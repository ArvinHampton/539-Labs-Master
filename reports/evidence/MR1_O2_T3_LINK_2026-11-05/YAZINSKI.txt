                                                  PSEUDOPERIODICITY AND THE 3x + 1 CONJUGACY FUNCTION

                                                                                        JONATHAN YAZINSKI
arXiv:1102.5547v1 [math.NT] 27 Feb 2011




                                                   Abstract. The 3x+1 function T : N → N is defined by T (x) = 3x+1     2
                                                                                                                            for x odd and T (x) = x2 for
                                                   x even. The function T has a natural extension to the 2-adic integers Z2 and there is a continuous
                                                   function Φ which conjugates T to the 2-adic shift map σ. Bernstein and Lagarias conjectured that
                                                   −1 and 13 are the only odd fixed points of Φ. In this paper we investigate periodicity associated
                                                   with Φ, a property of the map which is a natural extention of solenoidality. We use it to show
                                                   that there are nontrivial infinite families of 2-adics that are not fixed points of Φ. In particular,
                                                   we prove that three sequences of farPoints of 2-adics are finitely pseudoperiodic, providing more
                                                   evidence supporting the Φ Fixed Point Conjecture.

that 2-power.


                                              2. Main Results
   We now provide evidence supporting the Φ Fixed Point Conjecture by demonstrating a periodicity
associated with Φ and a related property which we will call pseudoperiodicity. Solenoidality allows
us to study the action of Φ on the first k digits of a 2-adic; however, periodicity will allow us to
look at beginning of the infinite “tail” end. First, we define what it means for a sequence to be
pseudoperiodic.
Definition 2.1. Let X be a set, and let {an } be a sequence (where a : N → X). For all n ∈ N we
say that the n-th term an is pseudoperiodic if
                                         ∃m ∈ N ∀r∈ N+ an+mr = an
We say that the sequence {an } is pseudoperiodic if all of its terms are pseudoperiodic.
    We will also say that the sequence {an }n≥k is pseudoperiodic if we replace “For all n ∈ N” in the
above definition with “For all n ≥ k”. It will be convenient in some applications to take X ∪ {∞} ,
where X ⊆ R to be the codomain of a and say that in this case {an } is finitely pseudoperiodic
when all terms an 6= ∞ are pseudoperiodic.
    Hence a sequence is pseudoperiodic if for every term in the sequence, there is some period m with
which that term will repeat in the sequence. For example, every periodic sequence is pseudoperiodic.
For a somewhat less trivial example, consider b : N → N, where bn is defined to be the smallest
positive prime dividing n + 2. The pseudoperiodicity of this sequence is reminiscent of the sieve of
Eratosthenes.
    Because Φ is solenoidal, “the action of Φ on the first k digits of a 2-adic” is well defined. That

point of Φ mod 2k when Φ (x) ≡ x. Consequently, whenever x is a fixed point mod 2k , we can ask
