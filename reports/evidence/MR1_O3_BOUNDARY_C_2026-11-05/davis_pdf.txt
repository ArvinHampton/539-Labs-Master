The answer



Theorem (Brunault & Neururer, 2020)
Let f be a normalised newform on Γ0 (N ) with weight k. Let Q(f ) be the
field generated by all the Fourier coefficients of f . Let
σ = ( ac db ) ∈ SL2 (Z). Then the Fourier coefficients of f |k σ lie in the
cyclotomic extension Q(f )(ζN 0 ) where N 0 = N/(cd, N ).

The answer



Theorem (Brunault & Neururer, 2020)
Let f be a normalised newform on Γ0 (N ) with weight k. Let Q(f ) be the
field generated by all the Fourier coefficients of f . Let
σ = ( ac db ) ∈ SL2 (Z). Then the Fourier coefficients of f |k σ lie in the
cyclotomic extension Q(f )(ζN 0 ) where N 0 = N/(cd, N ).

    This result holds more generally for modular forms on Γ1 (N )
    The proof is purely classical
