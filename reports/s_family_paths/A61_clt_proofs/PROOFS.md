## Item 1. Shift bound on the third derivative (known item 1)

**Statement 1.1 (per term; this is the claim "|B'''| <= (v(1-2p)+t0 v p)/cos(t0/2)³").** Let 0 < p <= 1/2, v = p(1-p), y real with |y| <= t < π, and h = p e^{iy}/(1-p+p e^{iy}) (so h = q e^{iy}/(1+q e^{iy}) with q = p/(1-p), the quantity B'''(iy;q) = h(1-h)(1-2h) of A59). Then
 |h(1-h)(1-2h)| <= v[(1-2p) + p|y|]/cos(y/2)³ <= [v(1-2p) + t·v·p]/cos(t/2)³.
Constant 1, no modification. Equality holds in the first inequality at y = 0.
**Proof.** With e = e^{iy}: h = pe/(1-p+pe), 1-h = (1-p)/(1-p+pe), 1-2h = (1-p-pe)/(1-p+pe), so h(1-h)(1-2h) = v·e·(1-p-pe)/(1-p+pe)³ (exact identity, sympy-verified in `code/chk01_symbolic.py`). Numerator: 1-p-pe = (1-2p) + p(1-e), and |1-e^{iy}| = 2|sin(y/2)| <= |y|, so |1-p-pe| <= (1-2p)+p|y|. Denominator: |1-p+pe|² = (1-p)²+p²+2p(1-p)cos y = 1 - 4v sin²(y/2) >= 1 - sin²(y/2) = cos²(y/2), because 4v = 4p(1-p) <= 1. Since |y| <= t < π, cos(y/2) >= cos(t/2) > 0 and |y| <= t. QED
**Statement 1.2 (geometric factor).** For 0 < w < 1 and all real y, with g = we^{iy}/(1-we^{iy}): |g(1+g)(1+2g)| <= w(1+w)/(1-w)³.
Proof: 1+g = 1/(1-we), 1+2g = (1+we)/(1-we), so |g(1+g)(1+2g)| = w|1+we|/|1-we|³ <= w(1+w)/(1-w)³ (|1-we| >= 1-w, |1+we| <= 1+w). QED

## Item 2. Cos-sum (Abel) bound in minor arc region B (known item 2)

**Statement 2.1.** Let n >= 1, J = largest odd integer <= n, v_1 >= v_3 >= ... >= v_J >= 0 and θ real with sin θ ≠ 0, X = 1/|sin θ|. Then
 Σ_{j odd<=n} v_j (1 - cos jθ) >= Σ_{j odd, X+1 <= j <= n} v_j.
**Proof.** For odd J' put C(J') = Σ_{i odd<=J'} (1-cos iθ) = (J'+1)/2 - sin((J'+1)θ)/(2 sin θ) (the identity Σ_{i=1}^{M} cos((2i-1)θ) = sin(2Mθ)/(2 sin θ), by telescoping 2 sin θ cos((2i-1)θ) = sin(2iθ) - sin((2i-2)θ); M = (J'+1)/2). Hence C(J') >= (J'+1-X)/2 and C(J') >= 0, so C(J') >= h(J') := max(0,(J'+1-X)/2). Put v_{J+2} := 0 (the extended sequence is still nonincreasing). Abel summation: Σ_{j odd<=J} v_j(1-cos jθ) = Σ_{j odd<=J}(v_j - v_{j+2}) C(j) >= Σ_j (v_j - v_{j+2}) h(j) (coefficients v_j - v_{j+2} >= 0). Summing by parts back: = Σ_j v_j [h(j) - h(j-2)] with h(-1) := 0. Let j >= X+1. If j-2 >= X-1, both j and j-2 are in the linear range of h (h(J') = (J'+1-X)/2 iff J' >= X-1) and h(j)-h(j-2) = 1. If j-2 < X-1, then h(j-2) = 0 and h(j) = (j+1-X)/2 >= 1 because j >= X+1. For j < X+1, h(j)-h(j-2) >= 0 since h is nondecreasing. So the sum is >= Σ_{j >= X+1} v_j. QED
(The statement as written in A56 REPORT §1.3, "Σ_{odd j} v_j(1-cos jθ) >= Σ_{odd j >= 1/|sinθ|+1} v_j", is therefore correct with exactly this constant; an Abel bound of the form "-Σ v_j cos jθ >= -v_{j0}/|sinθ|" would NOT give it, the proof above uses the nonnegativity and monotonicity of the partial sums C(J').)
**Statement 2.2 (conversion used in `clt56.cell`, region B).** Let n >= n0 = 1467, θ ∈ [1.5/n, π-1.5/n], u in [ua,ub], v_j = v(ju/n). With Y0 = 3/n0 + 1/(1.5(1-1.5²/(6n0²))) < 1:

**Proof.** v_j = v(ju/n) is nonincreasing in j, so 2.1 applies. sin θ >= sin(1.5/n) on [1.5/n, π-1.5/n] (sin concave on [0,π]) and sin x >= x(1-x²/6), hence X <= n/(1.5(1-1.5²/(6n²))). Let j_min be the smallest odd integer >= X+1 (so j_min < X+3) and j_max the largest odd <= n (>= n-1). Since v decreasing, v_j >= (1/2)∫_j^{j+2} v(yu/n)dy, so Σ_{odd j∈[j_min,j_max]} v_j >= (1/2)∫_{j_min}^{j_max+2} v(yu/n)dy >= (1/2)∫_{X+3}^{n} v(yu/n)dy = (n/2)∫_{(X+3)/n}^{1} v(ux)dx. Now (X+3)/n <= 3/n + 1/(1.5(1-1.5²/(6n²))) <= Y0 (both terms decrease in n), the integrand is >= 0, and v(ux) >= v(ub x) for u <= ub (v decreasing on (0,∞)): the first inequality. The right-endpoint Riemann sum of a decreasing function is <= its integral: the second. (Y0 < 1 is asserted by the code through b_B > 0 and the flag n0·b_B >= 1.5.) QED

**Proof.** Li2'(z) = -log(1-z)/z (|z| <= 1). d/dy Li2(-e^{-uy}) = [-log(1+e^{-uy})/(-e^{-uy})]·(u e^{-uy}) = u log(1+e^{-uy}), so ∫_0^1 log(1+e^{-uy})dy = [Li2(-e^{-u}) - Li2(-1)]/u = [Li2(-e^{-u}) + π²/12]/u (Li2(-1) = -π²/12). d/dy Li2(e^{-uy}) = [-log(1-e^{-uy})/e^{-uy}]·(-ue^{-uy}) = u log(1-e^{-uy}), so ∫_1^2[-log(1-e^{-uy})]dy = [Li2(e^{-u}) - Li2(e^{-2u})]/u (both arguments in (0,1), integrand integrable). Add and halve. QED

## Item 22. Bounds on log A_n(e^{-u/n})

Let f_B(x) = log(1+e^{-ux}) (decreasing, f_B(0) = log 2) and f_G(x) = -log(1-e^{-2ux}) (decreasing on (0,∞), f_G(1/2) = g(u)). By 11.1 at x = e^{-u/n}: log A_n = Σ_{j odd<=n}f_B(j/n) + Σ_{n/2<l<=n}f_G(l/n).
**Statement 22.1 (upper, even n >= 2, all u > 0):** log A_n(e^{-u/n}) <= nΦ1(u) + log 2 (hence also <= nΦ1(u)+log 2+g(u), the form stated in A56).
**Proof.** For odd j >= 3, f_B(j/n) <= (n/2)∫_{(j-2)/n}^{j/n}f_B (decreasing); for j = 3,...,n-1 these intervals are disjoint inside [1/n,(n-1)/n], and f_B(1/n) <= log 2. So Σ_odd f_B(j/n) <= log 2 + (n/2)∫_0^1 f_B. Geometric, n even: f_G(l/n) <= n∫_{(l-1)/n}^{l/n}f_G; l = n/2+1..n gives the disjoint union [1/2,1]: Σ <= n∫_{1/2}^1 f_G. Sum: <= nΦ1 + log 2. QED
**Statement 22.2 (lower, all n >= 1, u > 0):** log A_n(e^{-u/n}) >= nΦ1(u) - (1/2)log 2 - g(u).
**Proof.** f_B(j/n) >= (n/2)∫_{j/n}^{(j+2)/n}f_B; the intervals for odd j <= n cover [1/n,(j_max+2)/n] ⊃ [1/n,1] (j_max >= n-1): Σ >= (n/2)∫_{1/n}^1 f_B >= (n/2)∫_0^1 f_B - (n/2)(1/n)f_B(0) (f_B <= f_B(0)). f_G(l/n) >= n∫_{l/n}^{(l+1)/n}f_G, l_min = ⌊n/2⌋+1 <= n/2+1: Σ >= n∫_{1/2+1/n}^{1}f_G >= n∫_{1/2}^1f_G - n(1/n)f_G(1/2) = n∫_{1/2}^1 f_G - g(u). QED
**Remark (what is not proved).** The upper bound with "+log 2 + g(u)" is claimed in the A56 docstring for all n; I prove it for even n only (the only parity in which it is used: e_n is a term of E_d). For odd n the same argument leaves an extra term (1/2)g(u(1-1/n)); I have not proved the stated form for odd n and it is not needed.

## Item 23. Chernoff bound, convexity, evaluation

**23.1 (Chernoff).** For any u_c > 0 and r = e^{-u_c/n}: since all a_n(m') >= 0 (11.1), a_n(m)r^m <= Σ_{m'}a_n(m')r^{m'} = A_n(r), i.e. a_n(m) <= A_n(r)r^{-m}. With m = n²ρ(α) and n = α√d: log a_n(m) <= log A_n + (u_c/n)m <= [22.1] nΦ1(u_c) + log 2 + u_cm/n = √d·F_k(α,u_c) + log 2, because (u_c/n)m = u_c d(1-α²)/(kα√d) = √d u_c(1-α²)/(kα). (A56 keeps the harmless +g(u_c).)
**23.2 (convexity).** ∂²F/∂α² = ∂²/∂α²[(u/k)(1/α - α)] = 2u/(kα³) > 0 (αΦ1 is linear in α). So for fixed u_c, sup over α ∈ [x,y] of F is max(F(x,u_c),F(y,u_c)) (endpoint mode of `tails56`), and for a window [A,B] with midpoint c, half-width hw: F(α,u) >= F(c,u) + F_α(c,u)(α-c) >= F(c,u) - |F_α(c,u)|hw (tangent mode; used for Ψ_low). u_c may be chosen freely per α-box (not per n), as the bound holds for each u_c > 0; `tails56` takes u_c = a float minimiser of F(mid,·) — any value is valid.
**23.3 (independent re-evaluation without convexity for Ψ_low).** `code/tail61.py` obtains Ψ_low by plain ball evaluation of F on 10 α-sub-balls × u-boxes of width 2e-4 (no tangent), the tail boxes use the endpoint evaluation (item 23.2). ## Item 24. Tiny-α part (α <= 0.005, n >= 2 even)

**Statement.** For odd 3 <= k <= 33, even n >= 2 with α = n/√d <= 0.005, and u_c := kα²/2:

**Proof.** Elementary inequality: 1 - e^{-x} = 2e^{-x/2}sinh(x/2) >= xe^{-x/2} (sinh y >= y). (ii) is its logarithm. (v): u_c = kn²/(2d) with n >= 2, so -log u_c = log(2d/(kn²)) <= log(2d/k) - log 4, and u_c/2 = kα²/4 <= 33·2.5e-5/4 < 0.001. QED
