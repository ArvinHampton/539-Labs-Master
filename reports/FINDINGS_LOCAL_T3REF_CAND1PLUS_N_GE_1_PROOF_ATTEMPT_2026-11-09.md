2. **PROVED — residue-vector equidistribution (Local-derived lemma LL-1).** For j ≥ 1 the map n mod 3^j ↦ (r₀,…,r_{j−1}), r_i := T^i(n) mod 3, is a bijection ℤ/3^j → {0,1,2}^j, and on each class T^j(n) = λ_r n + δ_r with λ_r = 4^{c₁}2^{c₂}/3^j (c_k = #{i: r_i = k}) and δ_r a constant of the class.
   Proof: if n = n₀ + 3^j t then, by induction on i ≤ j, T^i(n) = T^i(n₀) + A_i 3^{j−i} t with A_i = ∏_{i′<i} a_{r_{i′}} prime to 3 (for i < j the added term is ≡ 0 mod 3, so residues agree and the same affine branch applies). Hence the vector depends only on n mod 3^j. Injectivity by induction on j: if n₀, n₀′ agree mod 3^{j−1} and have equal vectors, write n₀′ = n₀ + 3^{j−1}s, s ∈ {0,1,2}; then T^{j−1}(n₀′) = T^{j−1}(n₀) + A_{j−1}s, and 3 ∤ A_{j−1} forces s = 0. 3. **PROVED — almost every n descends (Terras-type theorem for this map).** The set E := {n ≥ 3: T^j(n) ≥ n ∀ j ≥ 1} has natural density 0.
   Proof: by LL-1, the residue vector of a uniformly random class mod 3^j is uniform on {0,1,2}^j, so ln λ_r is a sum of j i.i.d. terms with values ln(1/3), ln(4/3), ln(2/3), mean μ = (1/3)ln(8/27) ≈ −0.40547 < 0 and variance σ² ≈ 0.32030.
