## 1. Fixes K1–K9 (PP 99593076), applied to the 1948 KK-counting file

- **K1 (wording, no new grade).** K1 stays **PROVED**. Record, as PP asked: the Δ = 2 mode is a BF-saturating double root (m²L² = −4, so Δ(Δ−4) = −4 has a repeated root Δ = 2). The linearized IR solutions are z² and z² ln z, both of which grow as z → ∞, so the IR-regular set has codimension 2. Alternate quantisation (1 ≤ Δ₋ < 2) does not change the IR count: the exponent pair {Δ₋, 4−Δ₋} is the same pair of positive numbers, both branches grow in the IR, and the quantisation choice is a condition at the conformal boundary, which here is replaced by the wall.

- **K2.**
  - K2 stays **PROVED** in the scope PP states: linearised analysis, finite χ-truncation, Δ ≠ 4. "1 per mode with Δ ≥ 4" in 1948 §2 is restricted to **Δ > 4**. Relevant modes (2 ≤ Δ < 4), including the BF double root Δ = 2, cost 2. For a flow *into* MN2 (IR end) this is correct; the UV-end count would be reversed and is not the setup used.
  - **E18-K2Δ4 (CONDITIONAL).** The Δ = 4 sub-clause of K2 is CONDITIONAL. At Δ = 4 the branches are a constant and z⁴; only the constant survives, and it does not decay. It counts as 1 only if the mode is exactly marginal and the IR endpoint may move along a conformal manifold. If the endpoint is pinned to exact MN2, it costs 2. Marginally (ir)relevant cases have log running and need a nonlinear analysis. The upgrade from linear counts to codimensions of a smooth IR-regular set uses the stable-manifold theorem and needs a finite χ-truncation in which the fixed point is hyperbolic (no Δ = 4 modes). For the untruncated PDE the "dimension" is formal. No H-invariant level-0 mode has Δ = 4, so K1 is unaffected. Higher levels (K3, OPEN) might.

  equivalently σ(χ) ∂_χ ln(e^{4A} e^{2C})|_w = (bulk T_{nχ} term). It is **algebraic in σ**, not a differential equation for n(χ). Where σ ≠ 0 it mainly constrains the χ-gradient of the worldvolume warp factors at the wall. It "fixes n(χ)" only if those gradients are given. - **K6 grade change, M-scaling retracted.**
  - **E18-K6 (OPEN).** K6 as stated in 1948 — expected intersection dimension ≤ −(M + 1), so the problem is overdetermined by at least M + 1, and "solutions are generically not possible" — is downgraded from CONDITIONAL to **OPEN**. The reasons, which NL accepts after checking PP's comparison of the two counts, are:
    - "Expected dimension" is a **heuristic**, not a theorem. A non-existence proof would need a Fredholm set-up of the wall-to-IR boundary-value problem, its index, and a transversality (Sard–Smale) argument over some parameter space. None of these is provided. A negative expected dimension does not prove non-existence: non-generic solutions can exist (symmetric, BPS or calibrated, K7), or the constraint maps can drop rank. There is also no generic family here, because the physical data are fixed numbers (N = 4880, 9760, Bolza).
    - The M-scaling of NL's count is **not established**. NL works in a reduced phase space of dimension 2N and then subtracts M Hamiltonian and (M − 1) momentum conditions at the wall. In a reduced phase space those constraints are already solved; re-imposing them at the wall is legitimate only for directions where the junction fixes a momentum that has no value partner in the reduced space. That is the situation for A′ in the singlet toy (A is removed by the global dilatation), which is why the toy wall curve is 1-dimensional and both counts give −1 at M = 1, n_rel = 0. For harmonics m ≥ 1 the warp-type values A_m(χ) are not removable by any global symmetry, their momenta have value partners, and H_m, P_m are already solved. PP's alternative count (wall values free, all momenta fixed by Israel, constraints imposed once, tangential χ-diffeos quotiented) gives a wall image of dimension N − 1, hence expected dimension **−1 − n_rel**, not −M − n_rel. Both counts reproduce the toy at M = 1; they differ for M ≥ 1 harmonics; the single calibration point cannot decide. The subtraction of H_m and P_m for m ≥ 1 is therefore **retracted**, not justified. An explicit M = 2 count with all metric functions (including the A_m values) and the wall-shape gauge is not done here (see §5).

This uses n_rel ≥ 1 from the H-invariant Δ = 2 mode (K1 + K2), so **expected dimension ≤ −(1 + n_rel) ≤ −2**. Conditionality: (a) the count is a heuristic, not a non-existence proof; (b) independence of the Hamiltonian constraint, the momentum constraint and the junction equations (K4 hypothesis above); (c) stated for both χ-branches, as follows.
    - **χ-uniform branch** (n(χ) constant; M = 1, no source-harmonic freedom). The two counts agree and both give −1 − n_rel ≤ −2.
    - **χ-smeared branch** (n(χ) has M ≥ 1 retained harmonics). The two counts differ (NL's retracted M-scaling vs PP's −1 − n_rel), but both are ≤ −(1 + n_rel) ≤ −2.
    - Non-existence is **not established** on either branch.

  - Insert C2 and k_x = f′ + D′/(6D) into Σk_fib = −8k_x: −(5/6)D′/D = −8f′ − (8/6)D′/D, hence (3/6)D′/D = −8f′, i.e. **½ D′/D = −8f′**. The right-hand side is independent of the S⁴ point, so D′ = c D on all of S⁴, with c := −16f′ constant.
