# order50 PREREG: residual smallness and Ξ (decision document; written and hashed before any numerics)
## Source audit (read-only)
order38 RG35, order42–46 NOTES/RESULTS, order47–49, v12 §"Where the shadow Ξ enters", v12 Open problems 1–2, order4a.
## (a) Written predictions for residual size
- order38: an arbitrary fixed matrix leaves floor r_B = 0.00206. This is a lower bound for fixed-matrix laws, not a prediction of r.
- order42–43: R = (a) + (b) is exact, but (b) ≈ −(a) has no written law. order44 showed the split is algebraically equivalent to the near-law itself, so it gives no independent prediction.
- order46: L_B (ii) is x-dependent, into shifted characteristics β+λ′_k with N′(x). There is no written bound or asymptotic for ‖R‖ from it. Deriving one would require choosing a truncation or norm estimate, which is not in the sources.
- v11/v12 theorem: relates ‖R(1/x)‖ = ‖R(x)‖/x exactly. It transports a size; it does not bound one. A "prediction of r on a new grid" from it would only be a consistency check (already done: order45/48).
- order37/39/41: den/|num| patterns, Category B, no functional form survives (den⁻² failed; the two-variable monotonicity passed). There is no written amplitude.
Conclusion: no written, non-fitted prediction of residual size exists.
## (b) Ξ
v12: Ξ is "not written as an explicit series with stated coefficients"; the sawtooth candidate (order4a) does not close; the Zwegers-type completion constants of H7 are not derived (Open problem 1). No written Ξ candidate is available to test, and inventing one is forbidden.
## Decision
No test is run. A test of any fixed-matrix or fitted amplitude would be vacuous (known to fail by order38/46) or invented. The package documents the obstruction.
Admissible next routes (not started; each needs a written derivation first):
(R1) derive an explicit bound for the k ≠ 0 part of L_B (ii) from c_k = Σ_{n≡k} e(·)/(2π²n²) (tail ≤ Σ 1/(2π²n²)); preregister it as an upper bound on ‖R‖ and test whether it is non-vacuous (bound < ‖S‖);
(R2) derive the H7 erf-completion constants (v12 Open problem 1), the only written route to Ξ.
Naming: RG* only, no labels L1–L7; "35-component law vector", 36 only as dim V. MAPS_CANDIDATES untouched; no Π/α1/fibre objects invented; no bridge claim.
