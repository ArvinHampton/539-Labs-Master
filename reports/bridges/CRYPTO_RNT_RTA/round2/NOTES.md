# round2 NOTES
1. The uniform limit of μ^C for odd k (5, 7, 11, 13) is observed exactly at finite j and is not proved. A Fourier argument does not close directly, because the step multiplies C by b_r, which makes the averaging operator non-diagonal in characters.
2. The thresholds 10⁻⁶ and 0.02 were fixed in advance. Every verdict is far from them (masses 0, 3^{−120}, or ≥ 0.2; excess ≤ 0), so they are not delicate.
3. The MIX-class row is a conditional prediction about an open question. A "holds" there (k = 8) confirms nothing.
4. The word weights come from Haar measure on Z₃ (P2). Integer seeds give the same law exactly over n ∈ [0, 3^j). No other seed distribution was tried.
