## 1. Continuum statement of the anomaly

A continuum D-brane with world-volume W in a spacetime with continuum NS-NS flux H = dB (or its continuum cohomology class [H] ∈ H³(X; ℤ)) is subject to the Freed–Witten obstruction:

W₃(W) + [H]|_W  =  0   in   H³(W; ℤ)

where W₃(W) ∈ H³(W; ℤ) is the continuum third integral Stiefel–Whitney class of the tangent bundle of W (the obstruction to a continuum Spin^c structure on W).

- If the sum is nonzero, the continuum world-volume fermion path integral (or the continuum B-field coupling of the open-string sector) is anomalous: the continuum partition function is not well-defined.
- Equivalent continuum packaging: the continuum D-brane charge must lie in twisted K-theory K_{[H]}^*(X), and W must be admissible for that twist.

The anomaly is a continuum consistency condition. It is not generated by residual discrete atoms.

## 2. What “resolution” means in this note

Within the continuum Category B layer, resolution means selecting one or more of the following so that the obstruction class vanishes or the continuum configuration is replaced by an admissible one:

1. Cancel W₃(W) against [H]|_W by choice of continuum H-flux.  
2. Restrict continuum wrappings to Spin^c world-volumes (W₃(W) = 0) in H-free regions.  
3. Pass to continuum twisted K-theory so that the charge lattice is K_{[H]}^* rather than ordinary K^*.  
4. Cancel the anomaly by continuum anomaly inflow from bulk / other branes (including M5 / NS5 magnetic sources of H).  
5. Avoid the wrapping: continuum D2 interfaces and D3 stacks of the existing notes are placed only on admissible cycles.

No residual discrete derivation forces which option is taken. Options below are continuum design paths.

Choose continuum NS-NS flux so that on every continuum D-brane world-volume W used by the framework:

Then the Freed–Witten sum vanishes identically.

**Continuum implementation sketch:**

- For each a, compute continuum W₃(W_a).  
- Source continuum H by NS5 (or reduced M5) magnetic charge so that the continuum periods of H on 3-cycles linking those world-volumes reproduce −W₃(W_a).  
- Continuum flux quantization of the companion notes remains in force:

**Constraint:** the same continuum H must be globally consistent (dH = 0 away from NS5 sources; continuum Bianchi with sources). Over-constrained systems may have no continuum solution; then Path I fails for that wrapping set and Path II–V are required.

## 4. Path II — Spin^c restriction (H-free admissible wrappings)

If continuum H vanishes in a region (or [H]|_W = 0), the condition collapses to:

W₃(W) = 0

i.e. W admits a continuum Spin^c structure. Resolution is by **restricting** continuum D-brane wrappings to Spin^c cycles only.

**Continuum implementation sketch:**

- Prefer continuum world-volumes diffeomorphic to Spin^c manifolds (e.g. many Calabi–Yau cycles with vanishing W₃, or continuum spacetimes with Spin structure so W₃ = 0 automatically when W is orientable and Spin).  
- Existing continuum D2 interfaces described as two-dimensional hypersurfaces: for a continuum 2+1 world-volume, H³(W; ℤ) is often torsion-limited; many low-dimensional continuum cases have W₃ = 0 automatically.  
- Continuum D3 world-volumes (3+1) require an explicit continuum Spin^c check in the chosen bulk metric / topology.

**Constraint:** if the continuum geometry demanded by warped throats or stellar-sink pictures forces a non-Spin^c cycle, Path II alone is insufficient.
