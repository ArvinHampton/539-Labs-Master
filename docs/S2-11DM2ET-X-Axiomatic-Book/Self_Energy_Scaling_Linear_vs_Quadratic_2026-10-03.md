## Two scalings, not one

The one-dimer self-energy in use is E_1 = G m^2 / a, with m = 110 kDa. It scales as 1/a. Doubling the separation halves E_1. That scaling is stipulated. It is not the Diósi integral.

The count then depends on how E_1 is multiplied by the number of dimers.

Linear, the row used so far: E_N = N E_1. Then N = hbar a / (G m^2 T). Log-log slope against separation is 1.
Quadratic, not selected: E_N = N^2 E_1. Then N = sqrt(hbar a / (G m^2 T)). Log-log slope is 1/2.
