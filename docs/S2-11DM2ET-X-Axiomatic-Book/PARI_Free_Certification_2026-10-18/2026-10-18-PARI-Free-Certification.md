# PARI-free certification of the s = 7 cusp-part results (K = Q(√35))

*2026-10-18, finished about 09:00 CDT. All work was done on the box. No PARI/cypari, no Heavy, no Grok prompts, no pushes, no emails. The original files were only read, never modified.*
*Folder: `2026-10-18-PARI-free/`. Every script listed below is free of PARI. Each `*.txt` file is the log written by the script of the same name.*

**Bottom line.**
- **Ray class group (part 1).** I constructed the ray class group mod 𝔭₂³𝔭₅𝔭₇∞₁∞₂ by hand. Using it, I assigned a class to each of the 140 components independently of PARI. This reproduces the PARI ray-class fit exactly:
  - the 22 empty (label, sign) slots and the content g of every component;
  - the Eisenstein, cusp and mixed norms;
  - the same 24 cusp components, with coefficients (1/48)e(k/60);
  - the 60 + 12 split.
- **L-values (part 2).** I computed exact Shintani cone sums. They give the 12 values L(0,χ) of the totally odd cusp characters of conductor (2√35) exactly, as elements of Z[ζ₁₂], and they equal the claimed values. With these values (and Shintani sums for the twisted series at x ≠ ±1), all 7 × 24 cusp-row identities hold to within 1.2·10⁻¹⁴.
- **No discrepancies were found.**

## Part 2: L(0,χ) via Shintani cones (`shintani.py`, `part2.py`, `cyc24.py` → `part2.txt`)

**Method.**
- Fundamental domain: the cones [v, εv) with ω ∈ {1, 5+√35} for principal ideals, and ω ∈ {10+√35, −3+√35} ⊂ 𝔭₁₃' for non-principal ideals.
- On each cone, ζ(0; x) = B₁(x₁)B₁(x₂) + 3(B₂(x₁)+B₂(x₂)), using \|N(t₁v + t₂εv)\| = \|Nv\|(t₁² + 12t₁t₂ + t₂²).
- Sums were done in exact rationals.
- L-values were computed exactly in Q(ζ₂₄), as Fraction vectors modulo Φ₂₄.

**Validations (Cat A):**
- Σ_c ζ(0,c) = 0 exactly (ζ_K(0) = 0).
- All 96 ζ(0,c) have denominator 70.
- L(0,χ) = 0 exactly for all 72 characters that are not totally odd.
- L(χ) = L(χ∘σ) for all 96 characters.
- Genus test: Σ_𝔞 ψ(N𝔞) at s = 0 equals (1−ψ(7))·L₂₀(0,ψ)·L₁₄₀(0,ψχ₁₄₀), with the right side computed from Dirichlet B₁ sums. This holds exactly for all 8 characters ψ mod 20.
- Two independent runs agree exactly: Cl mod 𝔣 at cone scale 70, and Cl mod 𝔪 at scale 140.

**Result (Cat A, given the Shintani s = 0 formula, which is a standard theorem):**
- The 12 totally odd, non-σ-invariant characters of conductor (2√35) take the following values. Here z = ζ₁₂, √3 = z + z⁻¹ and i = z³.

  | L(0,χ) | Value | Exact form in Z[ζ₁₂] | Characters |
  |---|---|---|---|
  | A | −(6+4√3) + (6√3−4)i | −12 − 8z + 12z² | 2 |
  | Ā | −(6+4√3) − (6√3−4)i | −8z − 12z² + 8z³ | 2 |
  | B | −12 + 4i | −12 + 4z³ | 2 |
  | B̄ | −12 − 4i | −12 − 4z³ | 2 |
  | C | (4√3−6) − (4+6√3)i | 8z − 12z² − 8z³ | 2 |
  | C̄ | (4√3−6) + (4+6√3)i | −12 + 8z + 12z² | 2 |

- **They are algebraic integers in Z[ζ₁₂] and equal the claimed values exactly.** Each value occurs twice, once for each member of a σ-pair.
- Matched label by label to PARI's `lvalues.txt` values (printed to 4 digits), the maximum difference is 2.3e-3, which is consistent with that rounding.
