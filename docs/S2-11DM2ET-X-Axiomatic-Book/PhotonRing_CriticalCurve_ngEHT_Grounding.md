## 2. Critical Curve in General Relativity

The critical curve is the locus, on the observer’s sky, of the impact parameters of null geodesics that asymptote to the unstable photon orbit. For a Schwarzschild black hole the critical impact parameter is exact:


## 3. From Critical-Curve Shift to Observed Ring Radius

```
Δr_ring / r_ring ≃ Δb_c / b_c
```

A fractional critical-curve shift of size ε therefore appears as a radial shift of the same order. Pure general relativity supplies no preferred finite thickness; any mechanism that truncates the infinite nesting of subrings imprints a finite radial width on the observed ring.
