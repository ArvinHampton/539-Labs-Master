# Einstein-Hampton action

The equation is the variation of this action. No extra stress is added after the fact.

S = S_5 + S_partial + S_+ + S_- + S_D2 + S_m

S_5 = 1/(16 pi G_5) \int d^5x \sqrt-g (R - 2 \Lambda_5),  \Lambda_5 = -6k^2
S_partial = 1/(8 pi G_5) \int d^4x \sqrt-q K
S_+ = -\tau_+ \int_{y=0} d^4x \sqrt-q_+
S_- = -\tau_- \int_{y=1} d^4x \sqrt-q_-
S_D2 = -T_2 \int d^3\xi \sqrt-\gamma,  \xi = (t, x_parallel, y)
S_m = \int_{y=0} d^4x \sqrt-q_+ L_m

\tau_+ = -\tau_- = 6k. Snap: \tau_- \to \tau_-(1+f_snap).

T^{(H)}_{\mu\nu} = -2/\sqrt-q_+ \delta S_D2/\delta q_+^{\mu\nu}
W(b) = e^{-k(b-b_0)} = \kappa_dark^{b/b_0-1}

D2 smear over the two transverse +U axes is required for a homogeneous fluid.
