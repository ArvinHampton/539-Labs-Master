## 2. u_L is pure Eisenstein (Cat A)

**Regions and ray classes.** Mod 𝔣 = 𝔭₂𝔭₅∞₁∞₂ the narrow ray class group is Cl⁺_𝔣 = Z/8 × Z/2. Each sign region of u_L is exactly one ray class:

| region | S+ | S− | T+ | T− |
|---|---|---|---|---|
| ray class | (5,0) | (1,0) | (1,1) | (5,1) |

- For every n ≤ 60 000 and all four regions, the lattice count equals the PARI ideal count in that class: `ideal_counts.txt`, max difference 0.
- A first run disagreed by 1 at some n > 29 000. That was box truncation, and it disappeared with a bigger box.

**Key relation.** With d = c(−,−) = (4,0), the class of a totally negative element ≡ 1 mod 𝔣:

  **S− = S+ + d, T− = T+ + d.**

So the coefficient of each character χ in 1_{S+} + 1_{S−}, and likewise in 1_{T+} + 1_{T−}, carries a factor (1 + χ̄(d)).

**Consequence.** A character χ = χ_{j,l} with χ(d) = −1 (j odd) is exactly a non-σ-invariant one, and it drops out. Writing g₁ = (1,0):

  u_L(w) = ¼ Σ_{j∈{0,2,4,6}} e(−j/8) [ U^cos_{χ_{j,0}}(w) + i·U^sin_{χ_{j,1}}(w) ],

  U^{cos/sin}_χ(w) = √y Σ_{𝔞 ⊂ O, (𝔞,10)=1} χ(𝔞) K₀(2πN𝔞·y/20) · {2cos, 2sin}(2πN𝔞·x/20).

Each of these 8 characters is a genus character χ = ψ∘N, with ψ of conductor dividing 20 and normalised so that ψ(7) = χ(𝔭₇). `genus_chars.txt` lists both admissible ψ for each χ, matched on all primes < 3000.

| χ | ψ | ψ·χ₁₄₀ | type |
|---|---|---|---|
| χ_{0,0} | 1 | χ₁₄₀ | (0,0) |
| χ_{0,1} | χ₋₄ | χ₋₃₅ | (1,1) |
| χ_{4,0} | χ₅² = (5/·) | χ₂₈ | (0,0) |
| χ_{4,1} | χ₋₂₀ | χ₋₇ | (1,1) |
| χ_{2,0} | χ₅³χ₋₄ | χ₅χ₋₇ | (0,0) |
| χ_{2,1} | χ₅³ | χ₅χ₋₄χ₋₇ | (1,1) |
| χ_{6,0} | χ₅χ₋₄ | χ₅³χ₋₇ | (0,0) |
| χ_{6,1} | χ₅ | χ₅³χ₋₄χ₋₇ | (1,1) |

Here χ₅ is the quartic character mod 5 with χ₅(2) = i.

**Coefficients.** λ_χ(n) = 1_{(n,10)=1} · Σ_{d|n} ψ(d)(ψχ₁₄₀)(n/d). These are exactly the Fourier coefficients of the Maass–Eisenstein series E_{ψ,ψχ₁₄₀}(·, ½). The coefficient identification is Cat A; calling the resulting form "Eisenstein" is standard (Cat B).

**Check (`eis_decomp.py`).** Let A(n) = #(S+ ∪ S−) and B(n) = #(T+ ∪ T−) at norm n. Both equal the formula above for **every n ≤ 60 000**, with error 1e-15.
- A first attempt failed only at 7 | n because the wrong partner ψ was used at 𝔭₇. That is fixed.
- Genus-periodicity test: A and B have 0 non-constant classes mod 280; T+ alone has 6/48. This explains the earlier wrong claim.

**Infinity types are consistent with Maass's construction (Cat A):** type (0,0) gives cos, type (1,1) gives sin, and mixed types cancel.

### 3.4 Eigenform basis (`cusp_forms.txt`, `nebentypus.txt`)

**Characters.** χ = χ_{j,l,1} with j odd mod 24 and l ∈ {0,1}. All 24 have conductor norm 140, i.e. 𝔣_χ = 𝔭₂²𝔭₅𝔭₇ = (2√35).

- Character orders: 24 for j coprime to 6; 8 for j ∈ {3, 9, 15, 21}.

**Forms.** One form for each orbit and each l:

  u_χ(z) = √y Σ_{n≥1} λ_χ(n) K₀(2πny) · {2cos(2πnx) if l = 0; 2i·sin(2πnx) if l = 1},
  λ_χ(n) = Σ_{𝔞 ⊂ O, N𝔞 = n} χ(𝔞)  (χ(𝔞) = 0 unless 𝔞 is coprime to (2√35)).

- λ_χ is multiplicative.
- λ_χ(p) = χ(𝔭) + χ(𝔭′) for split p; λ_χ(p) = 0 for inert p; λ_χ(p²) = χ((p)) for inert p.
- Level 19600. Nebentypus ω = χ₁₄₀·ω₀, where ω₀(n) = χ((n)) is an even character mod 35. This was checked consistent on 27 primes (values in `nebentypus.txt`).
- Cat B: the level formula d_K·N(𝔣_χ), cuspidality ⇔ χ ≠ χ∘σ, and newform status are standard Maass/Hecke theory and are not re-proved here.

**Exact combinations in the cusp components (Cat A).** For each cusp component c:

  u_c(w) = Σ_{12 forms χ} 2F̂_c(χ) · u_χ(w/140), with F̂_c(χ) = (1/48)·e(k_{c,χ}/60).

## 4. Splitting ψ

- **Scalar ψ (Cat A given §2).** Both representations of ψ use u_R alone, or u_L and u_R:
  - ψ(x) = (x/(π√35))(∫₀^{i∞}[u_R, R_x^{1/2}] − log ε/2);
  - the split-contour form.
  Both u_L and u_R are Eisenstein, so **ψ_cusp ≡ 0 and ψ = ψ_Eis**. The 37-rational checks and the Bernoulli/Shintani values from the earlier reports are therefore purely Eisenstein quantities.
- **ψ_Eis.** By linearity, ψ_Eis = Σ over the 8 genus characters of the (vector-valued, SL₂(Z)) period integrals of E_{ψ,ψχ₁₄₀}(w/20, ½), with the weights in §2.
  - At rationals: exact finite Bernoulli sums (Cat A).
  - Elementary closed form for the real-analytic function: **not obtained**.
  - Expectation (Cat B, untested): Eisenstein period functions at s = ½ are Herglotz-type. Candidate building blocks are the twisted double sums Σ_{m,n≥1} ψ₁(m)ψ₂(n)/(mx+n), plus the regularised F(x) = Σ(ψ_Γ(nx) − log nx)/n for the trivial-character pair, modulo elementary terms.
  - Radchenko–Zagier show that F is an S-cocycle modulo elementary functions via the weight-2 Eisenstein series. They also note Herglotz's evaluation of J(6+√35), the same unit as our ε. That is suggestive only.
- **ψ_cusp for the cusp rows (Cat A numbers, Cat B identification).** For c in the cusp set, Φ_c(x) = −(2/π)[−|x|J_U(x) + J_{u_c}(−1/x)] (no constant terms). It is the LZ period function of the cusp vector. At the 7 test rationals |Φ_c| ≤ 0.53 and it is nonzero; for example Φ₇₃(1) = 0.12045 + 0.17644i (`phi_cusp_rows.txt`).
  - At rationals, Φ_c equals the exact κ (Bernoulli/Shintani cone) sum, verified to 2e-14 last round. By the theta-lift structure these are combinations of additively twisted central values of the u_χ (Cat B; I did not evaluate L-values separately).

## 5. Certification independent of PARI

**Cl(K) = Z/2, by hand (Cat A).**
- The Minkowski bound is √140/2 ≈ 5.92, so only the primes 2, 3, 5 matter.
- 3 is inert.
- 𝔭₂ is not principal: x² − 35y² = ±2 has no solution mod 5.
- 𝔭₂² = (2) and 𝔭₂𝔭₅ = (5 + √35).
- The fundamental unit is ε = 6 + √35, from √35 = [5; 1, 10].

**|Cl⁺_𝔣| = 16 for 𝔣 = 𝔭₂𝔭₅∞₁∞₂ (Cat A).**
- The formula h·φ(𝔣)·2²/[U : U_{𝔣,1}] gives 2·4·4/2.
- ε ≡ 1 mod 𝔭₂ and ε ≡ 1 mod 𝔭₅, and ε ≫ 0. So U_{𝔣,1} = ⟨ε⟩ and the index is 2.

**The relations S− = S+ + d, T− = T+ + d (hand, Cat A).**
- β(−ν) = −β(ν), and a ↦ −a corresponds to β₀ ↦ −β₀ (β₀ = −2√35).
- So the S− (resp. T−) ideals are the S+ (resp. T+) ideals multiplied by the class of a totally negative element ≡ 1 mod 𝔣.
- d ≠ 0, because no unit is ≡ 1 mod 𝔣 and totally negative: −ε^k ≡ −1 mod 𝔭₅.
- Also σ(S+) = S−, since σβ₀ = −β₀. So d ∈ (σ−1)G.

**The 8 genus characters (hand, Cat A).**
- For ψ mod 20, ψ∘N is well defined on Cl⁺_𝔣. If α ≡ 1 mod 𝔣 and α ≫ 0, then Nα ≡ 1 mod 5 and Nα ≡ 1 mod 4, so Nα ≡ 1 mod 20.
- The 8 characters mod 20 give distinct ψ∘N. This uses Dirichlet's theorem on split primes, together with the fact that χ₁₄₀ is not a character mod 20.
- Each of them satisfies ψ∘N(d) = 1.
- Since |G| = 16, the characters with χ(d) = 1 number exactly 8, so they are exactly the genus characters.

**Conclusion.** u_L is Eisenstein is proved with no PARI input beyond what is re-derived above. The class-field step σ-invariant ⇒ ψ∘N is not even needed.

**Modulus (2√35)∞₁∞₂.**
- |Cl⁺_𝔪| = 2·φ(𝔪)·4/[U : U_{𝔪,1}] = 2·48·4/4 = 96, by hand (Cat A).
- The index is 4 because ε ≡ −1 mod 𝔭₇, ε² ≡ 1 mod 𝔪, and ε² ≫ 0.
- The group structure Z/24 × Z/2 × Z/2, the σ-action and the conductors are PARI results (bnrinit/bnrconductor, cypari2 2.2.4, with bnfcertify = 1 for the base field). They were not hand-certified; Cat A computational, PARI-dependent.

**Region ↔ ideal bijection.** It is elementary (the dictionary in §1). It was checked exactly against PARI's independent ideal enumeration up to norm 60 000.

**Fourier–integral interchange and sector-uniform Euler–Maclaurin: sketch only, Cat B.**
- For y ≥ y₀ > 0 the Fourier series and its derivatives converge absolutely and uniformly. There are O(X) lattice points mod γ with |Q| ≤ X, and K₀ and K₁ decay exponentially. So the interchange on [y₀, ∞) is dominated convergence.
- Near y → 0 one uses u = M⁻¹(u∘S). The cone sums at rational x are then expanded by Euler–Maclaurin on each Shintani cone; the cones [e₁, γe₁) and [f, γf) are closed sectors with non-null edge rays (Q(e₁) = Q(γe₁) = 1 > 0), so |Q| ≍ |ν|² uniformly on each sector.
- This yields the s·t^{−1/2} + κ + O(t^{1/2}) expansion whose κ was verified numerically (2e-14).
- I have not written out the error terms in full.
