# D2 stress tensor

T^{AB} = -2/\sqrt-g \delta S_D2/\delta g_{AB} from S_D2=-T_2\int\sqrt-\gamma.

Embedding \xi=(t,x_parallel,y).
\sqrt-\gamma = a b e^{-2kby}, \sqrt-g = a^3 b e^{-4kby}.

T^{tt}=T_2 e^{4kby} a^{-2} \delta^2(x_perp)
T^{parallel parallel}=-T_2 e^{4kby} a^{-4} \delta^2(x_perp)
T^{yy}=-T_2 e^{2kby}/(a^2 b^2) \delta^2(x_perp)
T^{perp perp}=0

\rho_5=T_2 a^{-2} e^{2kby} \delta^2(x_perp)
