# Executive Summary: Proca equation, 2026-10-03

The written kinetic term gives partial F + mu^2 A = J. In Lorenz gauge, (square + mu^2) A = J. Mass unselected. On the lock J = 0, so A = 0.

A nonzero mass leaves three degrees of freedom. mu = 0 is a second stipulation. The static field is a Yukawa potential with unselected range. The near-field deficit does not move. L1-L7 unchanged.
