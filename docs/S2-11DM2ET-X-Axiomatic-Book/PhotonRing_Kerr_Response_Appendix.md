## Leading-order response

At fixed spin χ and observer inclination i, the observed radial location of the critical curve (and therefore of the asymptotic photon ring) is a smooth function of the critical impact parameter b_c. For small fractional shifts the first-order response is

```
Δr_ring = (∂r_ring / ∂b_c)_{χ,i} · Δb_c
```

When radii are expressed in units of GM/c², the partial derivative is a dimensionless number of order unity. Consequently

```
Δr_ring / r_ring ≃ R(χ,i) · (Δb_c / b_c)
```

where the response factor R satisfies R(χ,i) = O(1) for all astrophysically relevant spins and inclinations.

## Explicit low-spin behaviour

For a Schwarzschild black hole (χ = 0) the critical impact parameter is exact:

```
b_c = 3√3 M ≈ 5.19615 M
```

In the slow-rotation limit the prograde and retrograde critical impact parameters admit the expansions

```
b_c^± ≈ 3√3 M ∓ 2χ M + O(χ²)
```

The corresponding shift in the observed ring radius inherits the same linear spin correction at leading order. The response factor R therefore remains close to 1; the fractional correction induced by moderate spin (|χ| ≲ 0.7) is only a few tens of percent at most.

## Practical implication for the model prediction

Because R is of order unity, a fractional critical-curve shift of size

```
Δb_c / b_c ~ 243/4880 ≈ 0.0498
```

still produces an observable radial thickness (or offset) of the same order:

```
Δr_ring / (GM/c²) ≈ 0.05
```

Spin and inclination modulate the precise numerical prefactor, but they do not change the conclusion that the closed ratio 243/4880 sets the characteristic scale that next-generation arrays should target. The expansion therefore leaves the original grounding note unchanged in its essential claim while making the spin dependence explicit for later precision work.
