# Density vs Isolation

**Status:** `RH_OPEN_DEBT_ARGUMENT_NOT_A_PROOF`

| | Density | Isolation |
|---|---------|-----------|
| Object | Bulk N(σ,T) | Local geometry |
| Feeds A | Yes: M ⇒ A ≪ M log T | Only if strong (e.g. Iso_H) |

Density counts zeros in a region; isolation constrains local geometry. Mass-with-A needs density-type polylog M or Iso_H. Half-isolation and Levinson isolation are different geometric objects; neither is Iso_H.
