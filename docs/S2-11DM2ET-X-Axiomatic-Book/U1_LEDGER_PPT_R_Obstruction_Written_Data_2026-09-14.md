2. Comparison against Criterion 3

C1. Against an algorithm R.
Sought: a PPT procedure that, given oracle access to a game adversary A, outputs a witness or a decision for Π, with the advantage relation of I3.
Written files name R and write the inequality shape. They do not specify inputs of R, how R wraps A, how R plants a Π instance into a digest y, how R extracts an inner path from a game win, or how R simulates SHA3.
Tracks C1 through C4 describe schedules. They do not describe R.
Result: no algorithm. Criterion 3 stays unmet.

C2. Against the SHA3 sandwich.
Public H evaluates SHA3, then T3 five hundred thirty-nine times, then SHA3 again.
A Preimage or Collision win is a statement about digests. Π is a statement about an inner integer path, optionally residual-constrained.
Planting a Π target y as an inner endpoint requires programming or inverting the outer SHA3. Extracting an inner endpoint from a digest requires opening the outer SHA3.
No random-oracle programming lemma, no indifferentiability statement for the wrapper, and no collision-transfer lemma from H to the inner map is written on Master.
Result: no composition lemma. Criterion 3 stays unmet.

C3. Against instance-space agreement.
Π instances may demand O_res-indexing, fiber membership, or permanent-class evaluations.
Public games do not demand those predicates.
An adversary that wins a public game need not return a residual-legal path.
A reduction that drops the residual predicates changes Π into unrestricted fixed-round inversion of Canonical T3. That changed problem is not the written Π, and I8 plus I9 forbid treating it as hard from present data.
A reduction that adds the predicates to the public games changes the written games.
Result: games and Π are not the same instance space. Criterion 3 stays unmet.

C4. Against a hardness source.
Π is not proven hard.
Free Canonical T3 is short on the written flux seed and on the written tower seeds 20 and 21.
Book HQCC 539 plus or minus 1 and Banach λ are not Canonical T3 and are refused by the No-Go.
Packaging 18 plus 521 is a COUNT. Resonant hard budget is an interpretive lock, not a mixing-time theorem and not a clock.
SHA3-512 Category A properties under Grover or classical sponge bounds do not transfer to the T3 body without the missing composition lemma of C2, and a SHA3-only bound would not be a reduction to Π.
Result: no written hardness that R could carry. Criterion 3 stays unmet.

C5. Against engineering substitutes.
Avalanche near one half, KAT agreement, constant-time selection, and side-channel traces do not produce an advantage inequality.
T4121 set-aside is an engineering choice.
Result: no substitute for R.
