# Proca equation

Date: 2026-10-03
Status: exploration of the written kinetic term. Mass unselected. Not a lock output.
CORE_FREEZE unchanged. Old ingredients stay retired. No new residual-flux object.

## Equation

The Proca-like term for the axial field A_mu gives the field equation

partial_nu F^nu mu + mu^2 A^mu = J^mu,

F_mu nu = partial_mu A_nu - partial_nu A_mu. In Lorenz gauge, partial_nu A^nu = 0, this is

(square + mu^2) A^mu = J^mu.

The mass mu is unselected. The current J is the axial current of a spin density. On the lock the five-piece stress has no spin density, so J = 0 and A = 0 is the solution.

## Degrees of freedom

A nonzero mass breaks A to A + d lambda. The divergence of the field equation forces partial_mu A^mu = 0 when partial_mu J^mu = 0. Three degrees of freedom remain. Setting mu = 0 restores the gauge symmetry and drops the count to two. That is a second stipulation, not a derivation of the mass.

## Static field

For a static point source the potential falls as exp(-mu c r / hbar) / r. Range lambda = hbar / (mu c) is unselected. An 8 nm range dies by 137 nm. A 137 nm range dies by 5.40 um. The range that matches the census scale is 1.12 times 10^37 m.

## What it does not do

The equation does not raise the near-field scale 2.26 times 10^{-39} per metre. It does not set T^lambda_mu nu on the Levi-Civita lock. It does not select 18 fs, 137 nm, or 539. L1 through L7 are unchanged.
